Schema funzionale

Cosa fa l'app, chi fa cosa e in che ordine. Diario della pressione per Android, con dashboard web e report per il medico.

Il flusso dal telefono al medico

Percorso dell'utente

  1. Installa l'app dal link pubblico /download (in futuro Play Store).
  2. Accede con Google una sola volta e dà il consenso privacy. Google serve solo a creare e ritrovare l'account.
  3. Accetta le condizioni d'uso: senza accettazione l'app non si apre. Ogni accettazione è registrata (account, email, telefono, versione, impronta del testo, data).
  4. Ogni giorno sblocca con impronta o PIN del telefono. Resta collegato finché non sceglie «Esci».
  5. Registra una misura: a voce (SYS, DIA, PUL, controllati e confermati a schermo) oppure fotografando il display (Upgrade).
  6. Consulta: ultima misura, settimana, Report con grafico e riquadri.
  7. Condivide: PDF o Excel dal telefono, oppure Web Dashboard → «Invia al medico».
  8. Cambia telefono: accede con Google e ritrova tutto. Esce o cancella l'account quando vuole.

Livelli

BASE · GRATIS misure a voce, grafici, report PDF ed Excel, promemoria, Web Dashboard, link al medico.

UPGRADE scansione con AI: foto del display del misuratore e, in arrivo, documenti medici (valori in tabelle e grafici). Usa la chiave Anthropic dell'utente: paga lui, direttamente ad Anthropic.

Regole fisse

  • Nessuna diagnosi, nessun consiglio, nessun giudizio sui valori: niente zone colorate né «nella norma».
  • Etichette sempre SYS, DIA, PUL. Pressione e battiti mai nello stesso grafico.
  • Grafici: 7 giorni, un punto per giorno = media di tutte le misure del giorno (spiegato prima dei grafici), valore scritto accanto, asse solo con i numeri dei giorni.
  • Stesso PDF A4 dall'app e dal web; dal web si scarica subito come file.
  • Niente rosso da nessuna parte: SYS viola, DIA verde acqua, PUL ambra. Nessun colore indica «bene» o «male».
  • Bilancia mattina/sera: solo il confronto delle medie, senza giudizio.
  • Dati legati a un codice anonimo; foto e file elaborati e non salvati.
  • Il gestore paga solo il server (gratuito); ogni utente paga la propria AI.

Sicurezza e dati

  • Telefono: una chiave privata che non esce mai dal telefono firma ogni richiesta; il server rifiuta firme non valide o orari sbagliati di oltre 5 minuti.
  • Web: codice monouso di 60 s nella parte # dell'indirizzo, scambiato con un cookie di 7 giorni. «Esci» sul telefono chiude anche il web.
  • Link al medico: sola lettura, periodo fisso, scadenza 1–30 giorni, ritirabili; niente email né account.
  • Database: solo impronte SHA-256 di codici, cookie e link; chiavi Anthropic cifrate AES-GCM legate all'account.
  • Dati personali: nessun nome; foto e file elaborati e scartati; dati in UE; cancellazione account immediata (resta solo la prova dell'accettazione).

Pubblicare una versione

  1. Modifica su un ramo → pull request → unione in main.
  2. GitHub Actions: aggiorna le tabelle D1, pubblica il Worker, compila l'APK, crea la release v0.1.N, mette l'APK su /download.
  3. Il sito cambia subito; l'app si aggiorna installando il nuovo APK.

Estendere

La dashboard è a moduli: le analisi saranno un nuovo modulo in web.ts e app.js, con accesso, periodi, invio ed export già pronti.
