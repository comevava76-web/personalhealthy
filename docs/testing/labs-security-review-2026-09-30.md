# Local lab import and security review — 2026-09-30

Implemented Android PDF/image import with bundled local OCR and PDF text extraction, explicit review and confirmation, fixed analyte codes and numeric fields. Original documents and OCR text are not sent to the API. Only confirmed date, analyte, value, unit and reference are synchronized for history. Supported catalog: 35 common tests; unfamiliar layouts and missing units require review and can be omitted. Existing blood pressure Scan remains an optional external AI feature.

Android and browser follow IT/EN/DE/FR system languages with English fallback. Dashboard offers Share and PDF download, with separate lab trends by test and unit. Lab sharing exports a PDF rather than issuing a bearer link.

Security changes include mandatory Google nonce and single-use token checks, canonical-message replay protection, atomic one-time browser codes, session revocation on recovery, explicit administrator provisioning, canonical versioned consent and separate health-data consent, strict lab schema and ownership, bounded bodies, safe log fields, account deletion cleanup and subscription access for personal history. CI gates deployment on tests and signed APK production. Failed security scans preserve previous findings and mark the latest attempt incomplete.

Validation: Android debug build and four parser unit tests passed; 168 local functional checks, dedicated lab security checks, eight timezone checks and eight lab browser views passed in prior runs. Six-page architecture layout passed. Signed release build and APK v2/v3/v3.1 verification passed. The release CI rotation script also passed. The complete browser dashboard suite found only a missing favicon (404); a favicon is included and the suite is repeated before promotion. Real-device OCR, Google account recovery with the new certificate and varied laboratory document layouts still require validation.
